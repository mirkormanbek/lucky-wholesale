# Lucky Wholesale — инструкции для Claude

Оптовый сайт Lucky Sport: https://opt.luckysport.kz. Подробности по коду — в `README.md` и `docs/`.

## Для кого сайт и зачем

- Lucky Sport — один из крупнейших продавцов кимоно для дзюдо на Wildberries; также продаёт ассортимент партнёра-производителя (единоборства, экипировка).
- Сайт — витрина для **оптовых клиентов**: клубы, спортшколы, федерации, тренеры, магазины. Главная цель сайта — **заявка**, которая приходит менеджеру в Telegram.
- Основной рынок опта — **Россия** (95% покупателей кимоно на WB — из РФ), затем Казахстан. Оптовые отгрузки — со складов в Москве и Алматы; счёт клиентам из РФ выставляет юрлицо в РФ.
- Типичный покупатель: тренер собирает заказ родителей на 5–50 кимоно (детские размеры 140–175). Ему важны цена «от», таблица размеров, обмен размера и быстрый ответ в WhatsApp/Telegram.

## Как работать с владельцем

- Владелец — предприниматель, не разработчик. Общение на русском, простыми словами, без жаргона; шаги в панели Plesk/GitHub — пошагово.
- Перед изменениями кода: кратко опиши, что нашёл, и план. Крупные изменения — через PR, не прямым пушем в `main`.
- В конце: что изменено, как проверено, что владелец должен сделать сам.

## Критичные правила

- **Push в `main` = выкладка на рабочий сайт.** Workflow `.github/workflows/sync-wb.yml` деплоит на Plesk (хостинг PS.kz, сервер `srv-plesk24.ps.kz`) через lftp. Сливать в `main` только проверенное.
- **Репозиторий публичный.** Никаких секретов, закупочных цен, себестоимости, маржи, условий с партнёром, персональных данных клиентов — ни в коде, ни в docs, ни в коммитах.
- Секреты: только GitHub Secrets (`FTP_*`, WB API) и на хостинге — переменные окружения или закрытый файл `../lucky-wholesale-private/lead-settings.json` (права 600, вне document root). Пример без секретов — `config/lead-settings.example.json`.
- `public/warehouse/` — закрытый кабинет поставщика (вход через защищённую папку Plesk, `REMOTE_USER`). Не ослабляй эту проверку.
- `data/*.json`, `data/skus.csv` — выгрузка WB, вручную не редактировать. Бизнес-логика — в `config/` и `catalog/`.
- Не ломай форму заявки: `public/leads.php`, `public/lead-domain.php`, `public/leads.js`. После изменений в ней — тесты ниже и живая проверка на сайте владельцем.

## Команды

- Сборка витрины: `node scripts/build-storefront.mjs` (нужен PHP в PATH или `PHP_BIN`).
- Локальный запуск: `php -S 127.0.0.1:4235 -t public scripts/dev-router.php`.
- Тесты: `php tests/leads-domain.test.php`, `php tests/lead-settings.test.php`, `node tests/leads-integration.cjs`.
- Условия опта (минимальный заказ, оплата, склады) — `public/site-config.php`.
