# Lucky Wholesale

Оптовый каталог спортивных товаров Lucky.

## Что уже умеет проект

- забирает все карточки, размеры, SKU и фото из Wildberries;
- хранит структуру оптового каталога отдельно от категорий WB;
- поддерживает ручные товары, которых нет на WB;
- сохраняет все WB-карточки отдельно; объединение возможно только вручную после подтверждения;
- поддерживает цвета товара;
- хранит публичную цену в формате «от N»;
- конвертирует KZT в RUB и USD;
- обновляет валютные курсы из Национального Банка Казахстана;
- формирует отдельный публичный JSON, который позже будет использовать сайт.

## Архитектура

```text
Wildberries API ─┐
                 ├─> build-catalog ─> public/data/catalog.json ─> сайт
Ручные товары ───┤
Категории ───────┤
Overrides/дубли ─┤
Курсы валют ─────┘
```

### Исходные данные WB

- `data/products.json` — карточки WB.
- `data/categories.json` — категории WB.
- `data/skus.csv` — все размеры/SKU.
- `data/summary.json` — сводка WB.

Эти файлы вручную не редактируем.

### Наша бизнес-логика

- `config/catalog-categories.json` — дерево категорий оптового каталога.
- `config/category-map.json` — автоматические правила WB → наши категории.
- `config/pricing.json` — логика цен и валют.
- `config/catalog-behavior.json` — политика отображения цветов, похожих товаров и ручного объединения.
- `catalog/product-overrides.json` — скрытие карточек, объединение дублей и индивидуальные правки.
- `catalog/manual-products.json` — товары вне WB.
- `catalog/manual-products.example.json` — пример ручного товара с цветами, размерами и ценой.

### Сгенерированные файлы

- `data/catalog-internal.json` — внутренний каталог со служебными данными.
- `data/catalog-review.json` — очередь на ручную проверку похожих товаров. Похожесть не означает, что это дубль.
- `public/data/catalog.json` — безопасный публичный каталог для сайта.
- `public/data/categories.json` — публичное дерево категорий.
- `public/data/fx.json` — используемые валютные курсы.

## Цена

Базовая цена хранится в KZT как `priceFromKzt`.

Публично отображаем только:

```text
от 2 400 ₸
≈ 450 ₽
≈ $5
```

Внутреннюю сетку цен можно хранить в `priceTiers`, но build-скрипт её в публичный JSON не отдаёт.

## Цвета

Цвет автоматически читается из характеристик WB. Для ручного товара или исправления WB можно указать массив:

```json
"colors": ["Черный", "Красный", "Синий"]
```

По текущей политике разные WB-карточки и разные цвета показываются отдельными товарами. Цвет хранится как характеристика карточки. Никакого автоматического объединения по названию, бренду или цвету нет.

## Автоматизация

Workflow запускается:
- вручную из GitHub Actions;
- после изменения скриптов/config/catalog;
- по будням после публикации дневных курсов НБК.

WB API token хранится только в GitHub Secret `WB_API_TOKEN`.

Подробная модель данных: `docs/DATA_MODEL.md`.
