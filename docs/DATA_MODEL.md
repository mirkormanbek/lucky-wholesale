# Модель данных Lucky Wholesale

## Принцип

Wildberries — источник исходных карточек, но не источник структуры оптового каталога.

- `data/products.json` — сырые/нормализованные данные WB. Их вручную не редактируем.
- `config/catalog-categories.json` — наши B2B-категории.
- `config/category-map.json` — правила первичного распределения WB-карточек по нашим категориям.
- `config/catalog-behavior.json` — политика отображения карточек, цветов и похожих товаров.
- `catalog/product-overrides.json` — скрытие, объединение дублей и ручные правки WB-товаров.
- `catalog/manual-products.json` — товары, которых нет на WB.
- `data/fx.json` — курсы для KZT → RUB/USD.
- `public/data/catalog.json` — готовый публичный каталог для сайта.

## Похожие товары и возможные дубли

Карточки WB никогда не удаляются из импортированных данных. Совпадение названия или бренда не считается доказательством дубля. Система только формирует список похожих товаров для проверки. Все такие карточки продолжают показываться отдельно.

Объединение допускается только после явного ручного подтверждения через `mergeGroups`.

Пример:

```json
{
  "id": "boxing-pu-classic",
  "nmIDs": [111111111, 222222222],
  "title": "Боксерские перчатки PU",
  "categoryIds": ["boxing-gloves"],
  "priceFromKzt": 2400
}
```

У одной каталожной карточки после объединения могут остаться несколько WB nmID, фото, цветов и размерных вариантов.

## Цвета

Цвета поддерживаются на двух уровнях:

1. автоматически извлекаются из характеристик WB, если характеристика содержит слово «цвет / color»;
2. могут быть заданы вручную в override или в ручном товаре.

Текущая политика: разные WB-карточки разных цветов показываются как отдельные товары. Цвет сохраняется как характеристика. Автоматического объединения цветов нет. Если позже будет принято решение объединить конкретные карточки вручную, система технически это поддерживает.

## Ручной товар

Минимальный формат:

```json
{
  "id": "manual-boxing-gloves-pu",
  "title": "Боксерские перчатки PU",
  "brand": "Lucky Sport",
  "categoryIds": ["boxing-gloves"],
  "article": "PU-001",
  "colors": ["Черный", "Красный", "Синий"],
  "sizes": ["6 oz", "8 oz", "10 oz", "12 oz", "14 oz", "16 oz"],
  "priceFromKzt": 2400,
  "minOrderQuantity": 10,
  "photos": []
}
```

## Цена

В публичный каталог уходит только `priceFrom` — «от N».

Можно хранить внутреннюю сетку `priceTiers`, но build-скрипт специально не публикует её.

Базовая цена хранится в тенге. RUB и USD считаются из `data/fx.json` и отображаются как ориентировочные значения.

## Категории

Один товар может иметь несколько `categoryIds`. Это полезно для товаров, которые подходят сразу для нескольких видов спорта.

WB-категория сохраняется только как техническая информация и не определяет пользовательскую навигацию каталога.
