# Статистика магазина

Откройте `/warehouse/analytics.php` через защищённый вход владельца. В кабинете склада есть ссылка «Статистика магазина». Менеджерам и гостям отчёт недоступен.

Данные начинаются с внедрения. Периоды: сегодня, 7, 30 и 90 дней; часовой пояс Asia/Qyzylorda. Визит объединяет активность одного браузера без перерыва более 30 минут. Вкладки используют общий случайный идентификатор в localStorage. Обновление страницы добавляет просмотр, но не новый визит. Это оценка визитов, не число физических людей. Блокировщики, DNT/GPC, отключённый JavaScript и хранилище браузера могут уменьшать показатели.

События: page_view, category_view, type_view, product_view, cart_add, cart_remove, request_open, request_copy, whatsapp_click. Копирование заявки и клик WhatsApp НЕ подтверждают отправленный заказ или продажу. Блок действий показывает независимое число визитов с каждым действием, не последовательную воронку.

Пример ссылки: https://opt.luckysport.kz/?utm_source=instagram&utm_medium=social&utm_campaign=sambo
Для WhatsApp используйте utm_source=whatsapp. В метках задавайте только короткие названия кампаний, никогда имена, телефоны или email. Сохраняются только разрешённые символы и длины; полный URL, referrer path, search query, IP и контактные данные не собираются этой аналитикой. Переход без referrer/меток считается прямым или неопределённым. Технические журналы хостинга существуют отдельно.

Состояние хранится отдельно от товаров в sibling private directory `lucky-wholesale-private/traffic-state.json`, блокировка `traffic.lock`, атомарная запись. Нужны те же разрешения, что у склада. Удаление данных старше 90 дней выполняется при записи или открытии отчёта. Нет подписки на внешний сервис; используются ресурсы существующего хостинга. Клиентские события могут быть подделаны; это оперативная статистика, не платёжная отчётность. Защита от случайного разрастания: не более 20 000 сессий/200 000 событий в день, 500 событий на сессию в день; измерения ограничены 500 ключами с объединением прочих в other.

«Не учитывать мой браузер» в отчёте исключает будущие события этого браузера; старые данные не удаляются. Настройка действует только для текущего origin браузера.

Проверки без производственных данных:
`php tests/traffic.test.php`
`php -l public/traffic.php`, `php -l public/traffic-domain.php`, `php -l public/warehouse/analytics.php`
`node --check public/app.js`, `node --check public/traffic.js`, `node --check public/warehouse/analytics-ui.js`

Загрузка модуля аналитики из приложения асинхронная: его недоступность не должна останавливать каталог. Ошибки записи скрываются от покупателей и видны HTTP-статусом; отчёт сообщает об ошибке хранилища владельцу. Не хранить данные аналитики в Git.
