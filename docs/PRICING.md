# Цены для клубов

Базовые цены вносятся в закрытом кабинете (`/warehouse/`, «Товары с ВБ · цены» и складские товары) — как раньше.
Сайт показывает не базу, а **цену для клубов**: базу с наценкой категории и со скидками за объём.

## Закрытый файл

`/var/www/vhosts/luckysport.kz/lucky-wholesale-private/pricing-settings.json` — рядом с `lead-settings.json`,
вне папки сайта и вне Git, права **600**. Те же проверки места и прав, что у файла заявок (`lead_private_json`).
Пример без реальных цифр — `config/pricing-settings.example.json`.

| Ключ | Что значит |
| --- | --- |
| `categoryMarkupPercent` | Наценка в % по коду категории. Действует на категорию и все её подкатегории, если у подкатегории нет своей. `"default"` — для всех остальных категорий. `null` = не задано. |
| `russiaSurchargePercent` | Надбавка для РФ в %. `0` — не используется. |
| `volumeDiscountPercent` | Скидки за объём: порог (шт.) → % от цены «от минимального заказа». Пороги больше минимального заказа из `site-config.php`. `null` = ступень не показывается. |

Ключи, начинающиеся с `_`, — комментарии, сайт их пропускает. Любой другой незнакомый ключ, проценты вне диапазона
(наценка 0–1000, скидка 0–99) или ошибка JSON считаются поломкой файла.

## Расчёт

- Цена КЗ «от N шт.» (N — `minimumQuantity` в `site-config.php`) = база × (1 + наценка/100), округление до 100 ₸.
- Ступень КЗ = цена КЗ × (1 − скидка/100), округление до 100 ₸.
- Цена РФ = цена КЗ (или ступени) × (1 + надбавка РФ/100) / курс рубля НБ РК (`data/fx.json`), округление до 10 ₽.
- Доллары = цена КЗ / курс доллара НБ РК, округление до 1 $.
- Категория товара WB — та, что видит покупатель в каталоге (уточнение по названию, `storefront-categories.php`,
  совпадение с `app.js` проверяет `tests/category-refine.test.cjs`). При нескольких категориях берётся первая,
  у которой нашлась наценка.

| Состояние файла | Что на сайте |
| --- | --- |
| Файла нет | Базовая цена, как раньше, без ступеней |
| Наценки для категории нет и нет `default` | Базовая цена этого товара, без ступеней |
| Файл с ошибкой / неверные права | «Цена по запросу» у всех товаров, пока файл не исправлен (база не показывается) |

## Что видно снаружи

Наружу (HTML, данные каталога в странице, `wb-catalog.php`, `warehouse-catalog.php`, страница товара, разметка
schema.org) уходят только готовые цены по ступеням. База, наценка и надбавка остаются на сервере; кабинет за паролем
по-прежнему работает с базой. Исключение — ручные товары `catalog/manual-products.*`: их `priceFromKzt` хранится
в репозитории и в публичном `data/catalog.json`, поэтому базовые цены туда не вносить.

## Дилер

Кнопка «От 50 шт. и магазинам — дилерская цена по запросу» (порог — `dealerQuantity` в `site-config.php`) открывает
заявку с типом клиента «Дилер». Пометка ставится и сама, если в заявке 50 шт. и больше. В Telegram первая строка —
«ДИЛЕР — запрос дилерской цены».
