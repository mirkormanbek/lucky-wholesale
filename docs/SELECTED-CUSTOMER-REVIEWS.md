# Выбранные отзывы покупателей

Пять отзывов для тестового блока предоставлены владельцем скриншотами 13 октября 2026 года. Это ручной выбор владельца, не выгрузка и не проверка API. На всех скриншотах пять звёзд.

Тексты достоинств и комментариев соединены в цитату без изменения формулировок. Осторожная фраза Нины о дальнейшей носке сохранена. Для подписей используются только имена, без фамилий и отчеств. Год отзывов неизвестен, поэтому даты не показаны.

Аватары и ответы продавца не перенесены. Тексты выбранных отзывов сопоставляются с WB API по полным фрагментам и оценке 5; имена API могут быть обезличены. При нескольких совпадениях медиа не подставляется. Названия в карточках обозначают тип товара (кимоно/шлем), не точную модель или артикул. После совпадения API добавляется ссылка на товар по nmId; она не выдаётся за ссылку на конкретный отзыв.

Новый WB_API_TOKEN обновлён владельцем. 13 октября API отзывов успешно вернул первую страницу (5000 записей). Токен доступен только процессу отдельного GitHub Actions job; ключ и полные ответы API не выводятся. WB sync и production-деплой не запускаются. Следующий запрос вернул 429: для текущего токена используется пауза 12 минут 5 секунд между страницами. Предельная выборка — четыре страницы архива и по одной странице обработанных/необработанных отзывов. Если некоторые выбранные отзывы не найдены, остальные отзывы не подставляются.

Ссылки photoLinks и video берутся из соответствующей найденной записи. Разрешены известные домены CDN WB, включая geobasket.ru, полученный в реальном ответе API. Фото кэшируются в public/media/reviews; видео конвертируется из HLS в MP4 H.264 без звука (до 120 секунд). JSON содержит только выбранные совпадения, ID товара, дату, локальные пути и диагностические количества/домены, без полного списка покупателей. public/data/selected-review-media.json отражает фактический результат загрузки, включая ошибки и ненайденные записи.

Миниатюры добавляются только для совпавшего review key. Фото открывается в native dialog; видео получает src по нажатию. Закрытие и Escape останавливают видео и освобождают источник. При сбое файла с медиа исходные текстовые отзывы остаются доступны. Файл JSON загружается с сайта; браузер не обращается к приватному API WB.

Разметка в public/index.html, стили review-* в public/styles.css, навигация в public/app.js. При одном отзыве или отсутствии переполнения обе стрелки отключаются. На мобильном доступны свайп и кнопки; при reduced-motion плавная анимация отключена. Основной блок согласован владельцем 13 октября 2026 года. В этом релизе пять текстовых отзывов без медиа. Загрузка выбранных фото/видео продолжает выполняться отдельно в тестовой ветке; до получения production JSON содержит пустой массив reviews. Служебный API workflow не включён в релиз.
