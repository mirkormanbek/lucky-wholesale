# Выбранные отзывы покупателей

Пять отзывов для тестового блока предоставлены владельцем скриншотами 13 октября 2026 года. Это ручной выбор владельца, не выгрузка и не проверка API. На всех скриншотах пять звёзд.

Тексты достоинств и комментариев соединены в цитату без изменения формулировок. Осторожная фраза Нины о дальнейшей носке сохранена. Для подписей используются только имена, без фамилий и отчеств. Год отзывов неизвестен, поэтому даты не показаны.

Фото покупателей, пользовательские видео, аватары и ответы продавца не перенесены. Названия в карточках обозначают тип товара (кимоно/шлем), не точную модель или артикул. Прямые ссылки на конкретные отзывы отсутствуют; общая ссылка подписана как переход в магазин, а не в конкретный отзыв.

Новый токен WB_API_TOKEN обновлён владельцем. Его права на отзывы в этом изменении не проверялись. API и WB sync не запускались; секреты не читались и не выводились.

Разметка в public/index.html, стили review-* в public/styles.css, навигация в public/app.js. При одном отзыве или отсутствии переполнения обе стрелки отключаются. На мобильном доступны свайп и кнопки; при reduced-motion плавная анимация отключена. До согласования изменения остаются в draft PR 29.
