# Каталог Lucky: виды спорта и типы товаров

Покупатель может открыть каталог по виду спорта или по типу товара. Оба способа показывают те же SKU, без копий товаров. Размер, цвет, материал, бренд и возраст не являются отдельными ветками дерева.

## Совместимость

Старые ID не удалены. Идентификатор combat-boxing-mma теперь обозначает раздел «Бокс»; специализированные MMA-перчатки, рашгарды, шорты и щитки перенесены в новый родительский раздел mma без смены ID товаров или листовых категорий. Существующие ручные дополнительные категории склада сохранены и имеют приоритет над распознаванием названия. Фотостудия продолжает использовать основную категорию.

Все новые категории доступны в кабинете склада, включая пустые. Публичные быстрые карточки показывают только направления с опубликованными товарами. ВБ синхронизируется вручную; эта работа не запускает синхронизацию и не меняет цены или реальные записи склада. Распознавание ВБ дополнено для ММА, самбо, борьбы и боксёрских шорт; сборщик и клиент используют одинаковые правила. Материалы и размеры новых типов можно редактировать в public/warehouse/fields.json.

Изображения ММА, самбо и борьбы созданы встроенным ImageGen, оптимизированы как PNG с альфа-каналом. Это иллюстрации категорий, не фото конкретных SKU.

## Проверка

node tests/taxonomy.test.cjs — целостность дерева, совместимость ID, настройки конечных категорий, классификация и совпадение сборщика с клиентом. Дополнительно выполнена локальная сборка с четырьмя тестовыми карточками; Playwright desktop/mobile проверяет выбор спорта/типа, URL и перезагрузку, дополнительные категории владельца и скрытие их от менеджера. Реальные товары не менялись, платная обработка фотографий склада не запускалась.
