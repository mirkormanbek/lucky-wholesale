# Портреты шлемов: универсальная обработка v3

Состав и конструкция определяются по оригинальным фотографиям, без обязательного списка типов или ручного выбора. Нет общего Venum-референса для всех шлемов: сервер больше не подставляет его. Отдельное фото посадки необязательно; если загружено, совместимые анатомические ориентиры используются без копирования чужих деталей.

Инструкция требует определять только присутствующие мягкие опоры, открытые зоны, подбородочные элементы, бамперы, решётки и крепления. Отсутствующие компоненты не добавляются. Жёсткая защита сохраняет зазор перед лицом; мягкие элементы касаются только соответствующих опорных зон. Не задаётся одна обязательная форма проёма или подбородочная перемычка.

Это универсальная инструкция модели, а не отдельный проверенный классификатор или физический симулятор. Автоматического измерения геометрии или сертификации посадки нет. При недостатке исходных видов предписано предпочесть предметное фото выдуманной посадке. До принятия результата владелец сравнивает форму, маркировку и конструкцию с реальным товаром.

Портрет работает спереди; режим предметного белого фона не меняется. Выбранные оригиналы обязательны, ИИ-результаты вместо оригиналов блокируются сервером. Референс передаётся последним только при явной пользовательской загрузке, не сохраняется в галерею. Оценка включает его только при загрузке. pipelineVersion: headguard-v3; fitReferenceUsed отражает фактическое наличие референса.

Проверки: tests/studio-headguard-v2.test.php, tests/studio-headguard.test.php, tests/studio-headguard-sport.test.php и локальный multipart PHP/cURL -> mock API. Реальное визуальное качество требует отдельной платной проверки; её в этой задаче не выполняли.
